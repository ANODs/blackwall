BLACKWALL 0.2.5: подписки на компьютере снова скачиваются целиком.

### Что исправлено
- Windows, macOS и Linux: 0.2.4 сохраняла только первый кусок ответа подписки, поэтому при обновлении писала, что в подписке нет поддерживаемых серверов (серверы, уже бывшие в списке, оставались). Теперь ответ снова читается целиком: обычный, сжатый и переданный частями. Android это не затрагивало.

### Скачать
| Система | Файл |
|---|---|
| macOS 13+ (Apple Silicon) | `BLACKWALL-0.2.5-ru-macos-arm64.zip` |
| Windows (x64) | `BLACKWALL-0.2.5-ru-windows-x86_64.exe` |
| Linux (x64) | `BLACKWALL-0.2.5-ru-linux-x86_64.tar.gz` |
| Android 10+ (arm64, x86_64) | `BLACKWALL-0.2.5-android.apk` |

macOS: правый клик по приложению → «Открыть». Windows: SmartScreen → «Подробнее» → «Выполнить в любом случае». Linux: распакуйте, запустите `./install.sh`. Android: откройте APK и разрешите установку из этого источника.
