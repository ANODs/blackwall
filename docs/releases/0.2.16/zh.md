BLACKWALL 0.2.16：在运营商封锁服务器的网络中，备用服务器保持可用；并对全部代码做了一次仔细检查。

### 新增内容
- 被运营商封锁的服务器不再让连接一次次中断。服务会频繁重新读取设置，以前每次都会忘记当前服务器的失败记录，并为了一个未经检查的新“最快”服务器而放弃正在工作的备用服务器。现在，能传输流量的备用服务器会继续使用，新的主服务器只有在真实请求通过后才会启用，连接后立刻无法传输的服务器会在几秒内被放弃。
- 无法读取的设置会保存为 `config.json.unreadable`，而不是被空设置覆盖。
- 当默认路由为直连、而某个应用或网站必须走 VPN 时，无法识别所属应用的连接一律被拒绝。
- 普通 TLS：每个为其他证书签名的证书都必须是证书颁发机构。格式错误的签名不再会使服务停止。
- “阻止 IPv6”和“DNS 走相同路由”现在真正生效。没有任何作用的“通知”和“声音”已移除。
- 无法设置的严格断线保护会阻止连接启动，Linux 和 Windows 与 macOS 一致。在 Windows 上，服务器很多时它不再失败。
- 切换服务器后，经过旧服务器的 UDP（通话、游戏）会正确结束，并通过新服务器重新开始。
