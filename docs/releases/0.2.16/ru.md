BLACKWALL 0.2.16: резерв держится в сетях, где провайдер режет серверы, и внимательный проход по всему коду.

### Что нового
- Сервер, который режет провайдер, больше не роняет соединение раз за разом. Сервис часто перечитывает настройки, и каждый раз он забывал отказы текущего сервера и бросал рабочий резервный ради нового «быстрейшего», который никто не проверял. Теперь резервный сервер, который несёт трафик, остаётся в работе, новый основной берётся только после настоящего запроса через него, а сервер, который сразу после подключения ничего не пропускает, отбрасывается за секунды.
- Настройки, которые не удалось прочитать, сохраняются в `config.json.unreadable`, а не заменяются пустыми.
- Соединение, чьё приложение не удалось определить, блокируется всегда, когда маршрут по умолчанию прямой, а какое-то приложение или сайт держится на VPN.
- Обычный TLS: каждый сертификат, который подписывает другой, обязан быть удостоверяющим центром. Некорректная подпись больше не может остановить сервис.
- «Блокировать IPv6» и «DNS через маршрут» теперь работают. «Уведомления» и «Звук», которые ничего не делали, убраны.
- Строгий kill switch, который не удалось включить, не даёт соединению начаться: на Linux и Windows так же, как на macOS. На Windows он больше не отказывает при большом числе серверов.
- После смены сервера UDP (звонки, игры) через старый сервер корректно завершается и идёт через новый.
