BLACKWALL 0.1.1 — защита с момента загрузки и обновления без пароля.

### Что нового
- macOS: трафик удерживается с загрузки системы, пока не поднимется служба. Приложения, которые стартуют при входе, больше не успевают выйти в сеть мимо VPN. Включается само при «Запуске при входе» в режиме TUN, если включено автоподключение или есть приложения со своим VPN-правилом. Если служба не появилась за две минуты после входа, трафик отпускается.
- macOS: сетевой помощник обновляет себя сам, проверяя подпись релиза. Пароль администратора нужен один раз при установке. Переход с 0.1.0 попросит пароль в последний раз.
