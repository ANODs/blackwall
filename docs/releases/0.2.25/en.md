BLACKWALL 0.2.25: updates arrive without waiting an hour.

### What is new
- macOS, Windows, Linux: when a check for a new version gets no answer (the connection still coming up after a start, GitHub busy), the app asks again after 30 seconds, then 1 and 2 minutes, then every 5 minutes until it gets an answer. Before, it waited a whole hour, so a fix could stay away for a long time.
