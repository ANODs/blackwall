BLACKWALL 0.2.0 — сайты, обход DPI, UDP везде, QR-коды.

### Что нового
- Маршруты для сайтов: youtube.com со всеми поддоменами получает свой маршрут, как приложение. Правило самого приложения всегда главнее, поэтому закреплённое за VPN приложение из него не уйдёт.
- Обход DPI заработал: прямой маршрут, в котором TLS ClientHello уходит в виде, мимо которого проходят фильтры по имени сайта; способ подбирается для каждого сайта из трёх. У российского провайдера YouTube, который напрямую не грузится вовсе, через него открылся на полной скорости.
- UDP через все протоколы: VMess, Trojan и Shadowsocks теперь тоже его несут (игры, звонки, DNS), а не только VLESS.
- QR-коды: подписку можно добавить с камеры или из картинки на Android, из буфера обмена или с экрана на компьютере.
