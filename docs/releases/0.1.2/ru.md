BLACKWALL 0.1.2 — Android.

### Что нового
- Android 10 и новее: первая сборка приложения. Маршруты по приложениям (только через VPN, напрямую, без сети), резервные серверы, удержание приложений после отключения и уведомление с сервером, временем подключения и скоростью. Само возвращается после перезагрузки телефона, работает с системными «Постоянная VPN» и «Блокировать соединения без VPN». Интерфейс на русском, английском и китайском в одном файле.
- macOS: новый значок приложения, нарисованный для macOS 26.
- Политика конфиденциальности: [docs/privacy.md](../../blob/main/docs/privacy.md). Разработчику ничего не отправляется.

### Скачать
| Система | Файл |
|---|---|
| macOS (Apple Silicon) | `BLACKWALL-0.1.2-ru-macos-arm64.zip` |
| Windows (x64) | `BLACKWALL-0.1.2-ru-windows-x86_64.exe` |
| Linux (x64) | `BLACKWALL-0.1.2-ru-linux-x86_64.tar.gz` |
| Android 10+ (arm64, x86_64) | `BLACKWALL-0.1.2-android.apk` |

Сборка пока не подписана Apple и Microsoft. macOS: правый клик по приложению → «Открыть». Windows: SmartScreen → «Подробнее» → «Выполнить в любом случае». Android: откройте APK и разрешите установку из этого источника.

Приложение также готовится к выходу в Google Play. APK отсюда и приложение из Google Play подписаны разными ключами, поэтому одно не обновляет другое: чтобы перейти, сначала удалите установленное.
