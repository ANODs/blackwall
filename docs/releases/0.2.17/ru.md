BLACKWALL 0.2.17: сервер, который режет провайдер, отбрасывается втрое быстрее.

### Что нового
- В сети, где основной сервер режется, резерв включался примерно через полминуты после подключения, и всё это время ничего не открывалось. Сервис спрашивал мёртвый сервер дважды, подолгу ждал каждого ответа, а потом опрашивал резервные по одному. Теперь хватает первой проверки, она ждёт 5 секунд вместо 8, а резервные опрашиваются по три сразу: в работу идёт лучший из тех, что несут трафик.
