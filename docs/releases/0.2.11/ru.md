BLACKWALL 0.2.11: на Windows снова работают резервные серверы.

### Что нового
- Windows: проверка «возит ли сервер трафик» и замер скорости не работали, и BLACKWALL считал мёртвыми все серверы, в том числе рабочие. Поэтому резерв не мог взять работу на себя. Исправлено.
- Windows: если соединение с сервером обрывается, в логе и отчёте для GitHub теперь виден точный код ошибки системы. Это помогает понять, кто рвёт соединение: сервер, сеть или сам BLACKWALL.
