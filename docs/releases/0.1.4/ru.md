BLACKWALL 0.1.4 — Windows полностью.

### Что нового
- Windows: весь трафик идёт через VPN (режим TUN, на Wintun) прямо из окна, с маршрутом для каждого приложения, защитой после отключения и резервными серверами — как на macOS и Linux.
- Windows: kill switch на Windows Filtering Platform. Его фильтры остаются, если служба упала, поэтому мимо VPN ничего не уходит; строгий режим выпускает трафик только к VPN-серверам.
- Windows: при первом подключении система один раз спросит (UAC), можно ли установить службу BLACKWALL. Следующие релизы заменяют её сами, проверив подпись релиза.
- Windows: список приложений берётся из меню «Пуск».
