BLACKWALL 0.2.2: приложение для Mac снова запускается на macOS 13 и новее.

### Что исправлено
- macOS: приложение собиралось под самую новую macOS сборочной машины, поэтому Mac с системой хоть на минорную версию старше отказывался его открывать. Теперь ему нужна macOS 13 или новее.
- Обновления перед установкой проверяют, что новая версия запустится на этом Mac, а если она всё же не запустилась, сразу возвращают старую.
- Всё из 0.2.1: отчёт для обращений на GitHub в Настройках и автообновление в любой сборке.

| Система | Файл |

| macOS 13+ (Apple Silicon) | `BLACKWALL-0.2.2-ru-macos-arm64.zip` |
| Windows (x64) | `BLACKWALL-0.2.2-ru-windows-x86_64.exe` |
| Linux (x64) | `BLACKWALL-0.2.2-ru-linux-x86_64.tar.gz` |
| Android 10+ (arm64, x86_64) | `BLACKWALL-0.2.2-android.apk` |

macOS: правый клик по приложению → «Открыть». Windows: SmartScreen → «Подробнее» → «Выполнить в любом случае». Linux: распакуйте, запустите `./install.sh`. Android: откройте APK и разрешите установку из этого источника.
