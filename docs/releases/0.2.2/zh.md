BLACKWALL 0.2.2：Mac 版本重新可以在 macOS 13 及更新版本上启动。

### 修复内容
- macOS：应用之前按构建机器上最新的 macOS 构建，因此系统哪怕只旧一个小版本的 Mac 也无法打开它。现在只需要 macOS 13 或更新版本。
- 更新在安装前会检查新版本能否在这台 Mac 上启动；如果仍然无法启动，会立即恢复旧版本。
- 包含 0.2.1 的全部内容：设置中的 GitHub 问题报告，以及所有版本都能自动更新。

### 下载
| 系统 | 文件 |
|---|---|
| macOS（Apple 芯片） | `BLACKWALL-0.2.2-zh-macos-arm64.zip` |
| Windows（x64） | `BLACKWALL-0.2.2-zh-windows-x86_64.exe` |
| Linux（x64） | `BLACKWALL-0.2.2-zh-linux-x86_64.tar.gz` |
| Android 10+（arm64、x86_64） | `BLACKWALL-0.2.2-android.apk` |

macOS：右键点击应用 → “打开”。Windows：SmartScreen → “更多信息” → “仍要运行”。Linux：解压后运行 `./install.sh`。Android：打开 APK 并允许从该来源安装。
