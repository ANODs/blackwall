BLACKWALL 0.2.1: отчёт для обращений и автообновление в любой сборке.

### Что нового
- Отчёт для GitHub (Настройки, О программе): сохраняет свежий журнал в Загрузки и открывает новое обращение, куда его остаётся приложить. Ссылки, ключи, идентификаторы, имя пользователя и адреса серверов и сайтов убираются до записи файла.
- Обновления: теперь любая сборка знает, откуда брать релизы, в том числе собранная из исходников, поэтому тумблер «Автообновление» всегда есть в Настройках. Копии, собранные локально до этой версии, обновиться сами не могут: поставьте этот релиз один раз.

### Скачать
| Система | Файл |
|---|---|
| macOS (Apple Silicon) | `BLACKWALL-0.2.1-ru-macos-arm64.zip` |
| Windows (x64) | `BLACKWALL-0.2.1-ru-windows-x86_64.exe` |
| Linux (x64) | `BLACKWALL-0.2.1-ru-linux-x86_64.tar.gz` |
| Android 10+ (arm64, x86_64) | `BLACKWALL-0.2.1-android.apk` |

macOS: правый клик по приложению → «Открыть». Windows: SmartScreen → «Подробнее» → «Выполнить в любом случае». Linux: распакуйте, запустите `./install.sh`. Android: откройте APK и разрешите установку из этого источника.
