BLACKWALL 0.2.1: a report for bug reports, and updates that work in every build.

### What is new
- Report for GitHub (Settings, About): saves the recent log to Downloads and opens a new issue to attach it to. Links, keys, user ids, your user name and the addresses of servers and sites are taken out before the file is written.
- Updates: every build now knows where releases come from, including one built from source, so the Auto-update switch is always in Settings. Copies that were built locally before this version cannot update themselves: install this release once.
