BLACKWALL 0.2.1：问题报告，以及所有版本都能自动更新。

### 新增内容
- GitHub 问题报告（设置 → 关于）：把最近的日志保存到“下载”，并打开一个新问题，把文件附上即可。写入文件之前会去掉链接、密钥、用户 ID、你的用户名以及服务器和网站的地址。
- 更新：现在每个版本都知道从哪里获取新版本，包括从源码构建的版本，因此“设置”中始终有“自动更新”开关。在此版本之前本地构建的副本无法自行更新：请手动安装一次此版本。

### 下载
| 系统 | 文件 |
|---|---|
| macOS（Apple 芯片） | `BLACKWALL-0.2.1-zh-macos-arm64.zip` |
| Windows（x64） | `BLACKWALL-0.2.1-zh-windows-x86_64.exe` |
| Linux（x64） | `BLACKWALL-0.2.1-zh-linux-x86_64.tar.gz` |
| Android 10+（arm64、x86_64） | `BLACKWALL-0.2.1-android.apk` |

macOS：右键点击应用 → “打开”。Windows：SmartScreen → “更多信息” → “仍要运行”。Linux：解压后运行 `./install.sh`。Android：打开 APK 并允许从该来源安装。
