BLACKWALL 0.2.13: на Windows заработало автообновление.

### Что нового
- Windows: новая версия скачивалась и проверялась, но не ставилась. Windows не даёт переименовать запущенную программу тем способом, которым это делал BLACKWALL, и в логе было `not installed: FileBusy`. Теперь программа отодвигает себя способом, который Windows разрешает, и следующие версии будут ставиться сами.
- Эту версию на Windows нужно один раз скачать и запустить вручную: старая не может обновиться сама. Скрытую папку `.BLACKWALL-….staging` рядом со старой версией можно удалить.
