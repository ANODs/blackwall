Первая публичная сборка BLACKWALL — лёгкого VPN-клиента на Zig.

### Что работает
- Подписки по ссылке или ключи, вставленные напрямую (`vless://`, `trojan://`, `ss://`, `vmess://`); задержка до каждого сервера.
- Протоколы: VLESS (REALITY, Vision, TLS), Trojan, Shadowsocks (включая 2022), VMess. Транспорты: TCP, WebSocket, HTTPUpgrade, gRPC, XHTTP (stream-one).
- macOS: перехват всего трафика (TUN) с маршрутами по приложениям — через VPN, через выбранный сервер, напрямую или без сети. Программы, запущенные приложением, идут по его правилу. Работает фоновая служба, окно можно закрыть; состояние и скорость видны в строке меню.
- Блокировка при обрыве, защита после отключения (приложения со своим VPN-правилом остаются без сети) и резервные серверы: если сервер перестал отвечать, клиент переподключается, а затем переходит на отмеченные звёздочкой.
- macOS: обнаружение другого VPN, который мешает подключению.
- Windows и Linux: локальный SOCKS5-прокси на `127.0.0.1:1080`.
- Автоматическое обновление с проверкой подписи.

### Пока нет
- Перехвата всего трафика на Windows и Linux.
- UDP через Trojan, Shadowsocks и VMess; Hysteria2, TUIC, WireGuard; локального обхода DPI.
- Android.

macOS — основная проверенная система. Сборки для Windows и Linux пока проверены только автоматическими тестами.
