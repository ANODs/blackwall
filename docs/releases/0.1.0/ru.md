Первая публичная сборка BLACKWALL — лёгкого VPN-клиента на Zig.

### Что работает
- Подписки по ссылке или ключи, вставленные напрямую (`vless://`, `trojan://`, …); задержка до каждого сервера.
- Локальный SOCKS5-прокси на `127.0.0.1:1080`: приложения, настроенные на него, идут напрямую или через VLESS (TCP, REALITY, Vision).
- Маршруты по приложениям, статистика трафика, блокировка при обрыве и настройки IPv6 в интерфейсе.

### Пока нет
- Перехвата всего трафика (TUN), транспортов WS / XHTTP / TLS и правил по приложениям на уровне сети.
- Android.
