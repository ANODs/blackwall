BLACKWALL 0.2.7: подписки живут на экране серверов.

### Что нового
- Подписки переехали из настроек на экран серверов: под названием подписки её заметка от провайдера, без эмодзи и пустых строк.
- У подписки меню ⋯: обновить, скопировать ссылку, написать в поддержку, удалить.
- У сервера меню по правому клику (на Android долгим нажатием): скопировать ссылку, скопировать JSON для Xray, удалить ключ, добавленный вручную. Группа «Авто» копируется всеми ссылками сразу, а её JSON собирается с балансировщиком leastPing.
