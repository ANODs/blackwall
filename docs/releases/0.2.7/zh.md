BLACKWALL 0.2.7：订阅移到了服务器页面。

### 新增内容
- 订阅从设置移到了服务器页面：订阅名称下方显示服务商的说明，去掉了表情符号和空行。
- 订阅有 ⋯ 菜单：刷新、复制链接、联系支持、删除。
- 服务器有右键菜单（Android 上为长按）：复制链接、复制 Xray 的 JSON、删除手动添加的密钥。“Auto”组会一次复制全部链接，其 JSON 带有 leastPing 负载均衡。
