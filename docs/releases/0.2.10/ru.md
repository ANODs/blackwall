BLACKWALL 0.2.10: на Windows окно снова открывается, а если что-то сломается, вы узнаете, куда об этом написать.

### Что нового
- Windows: в 0.2.9 окно закрывалось сразу после открытия. Картинка иконки в трее лежала в памяти по невыровненному адресу, и SDL при её конвертации останавливал программу. Исправлено.
- Окно теперь пишет свой лог в файл `window.log` в папке настроек (`%APPDATA%\BLACKWALL` на Windows), без ссылок, ключей и адресов, как в отчёте. Лог прошлого запуска хранится рядом и попадает в отчёт для GitHub.
- Windows: если окно всё же упадёт, появится сообщение, где лежит лог, и кнопка, которая откроет новое обращение на GitHub и покажет файл, чтобы его приложить.
