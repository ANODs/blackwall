BLACKWALL 0.1.3 — Linux полностью.

### Что нового
- Linux: весь трафик идёт через VPN (режим TUN) прямо из окна, с маршрутом для каждого приложения, защитой после отключения и резервными серверами — как на macOS.
- Linux: строгий kill switch на nftables. Он остаётся в ядре, если служба упала, поэтому мимо VPN ничего не уходит.
- Linux: ни одна часть BLACKWALL не работает от root. Маленький `blackwall-tun` держит одно сетевое разрешение, которое запрашивается один раз через системное окно ввода пароля; обновления его сохраняют.
- Linux: `install.sh` добавляет BLACKWALL в меню приложений для вашего пользователя.

### Скачать
| Система | Файл |
|---|---|
| macOS (Apple Silicon) | `BLACKWALL-0.1.3-ru-macos-arm64.zip` |
| Windows (x64) | `BLACKWALL-0.1.3-ru-windows-x86_64.exe` |
| Linux (x64) | `BLACKWALL-0.1.3-ru-linux-x86_64.tar.gz` |
| Android 10+ (arm64, x86_64) | `BLACKWALL-0.1.3-android.apk` |

Linux: распакуйте, запустите `./install.sh`, откройте BLACKWALL из меню. Нужно ядро 5.7 или новее.
macOS: правый клик по приложению → «Открыть». Windows: SmartScreen → «Подробнее» → «Выполнить в любом случае». Android: откройте APK и разрешите установку из этого источника.
